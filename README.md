# 🐍 Python Foundations

Учебный репозиторий для глубокого освоения синтаксиса, внутреннего устройства, модель памяти, ООП и асинхронного программирования в **Python**.

Главный акцент — не просто поверхностное знакомство с языком, а понимание работы CPython "под капотом", чистый идиоматичный код (PEP 8) и создание надежных фундаментальных навыков для бэкенд-разработки.

---

## 🎯 Цели репозитория

- [ ] Освоение синтаксиса и стандартной библиотеки

- [ ] Понимание модели памяти и CPython

- [ ] ООП и протоколы

- [ ] Основы конкурентности (Concurrency)
